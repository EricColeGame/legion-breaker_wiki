## 단계별 설치 및 문제 해결 가이드

**Legion Breaker 다운로드**를 완료하고 시스템을 설정하는 과정은 매우 간단합니다. 다만, 일부 구형 Windows 환경에서는 사소한 설치 오류나 드라이버 충돌이 발생할 수 있습니다.

게임을 설치하고 무결성을 확인하는 단계는 다음과 같습니다:

1. 데스크톱 Steam 클라이언트를 실행하고 계정에 로그인합니다.
2. 게임 이름을 검색하거나 라이브러리 목록으로 이동합니다.
3. **설치**를 누르고 설치할 드라이브에 최소 500 MB 이상의 여유 공간이 있는지 확인합니다.
4. 설치가 완료되면 **플레이**를 클릭하여 최초 실행 시 필요한 DirectX 런타임 자동 점검을 진행합니다.
5. 인게임 설정 메뉴에서 해상도를 조정하고 모니터 주사율에 맞춰 프레임 제한을 활성화합니다.

수백 개의 유닛이 격돌하는 대규모 전투 도중 프레임 드랍이 발생한다면 아래의 문제 해결 표를 참고하여 빠르게 조치해 보세요.

| 발생 문제 | 발생 원인 | 권장 해결책 |
| :--- | :--- | :--- |
| **실행 시 DirectX 11 충돌 오류** | 구형 GPU 드라이버 또는 런타임 손상 | 그래픽 드라이버 업데이트, Microsoft 공식 웹사이트에서 DirectX End-User Runtimes 재설치 |
| **대규모 웨이브 시 미세 끊김(스터터링)** | 백그라운드 리소스 로딩 병목 현상 | Steam 저장 공간 관리자 메뉴를 통해 게임 설치 위치를 SSD로 이동 |
| **세이브 데이터 동기화 실패** | Steam 클라우드 동기화 충돌 | 네트워크 연결 확인, Steam 라이브러리에서 게임 우클릭 > 속성 > 설치된 파일 > 게임 파일 무결성 검사 실행 |
| **노트북 환경에서 낮은 프레임 발생** | 시스템이 내장 그래픽으로 기본 실행됨 | Windows 그래픽 설정에서 게임 실행 파일(.exe)을 외장 Nvidia 또는 AMD GPU로 고정 |

이러한 사전 조치를 취해두면 고난도 보스전에서 화면 전체가 마법, 아군 유닛, 화려한 파티클 효과로 뒤덮여도 **Legion Breaker 다운로드** 파일이 매우 안정적인 프레임을 유지할 수 있습니다.
