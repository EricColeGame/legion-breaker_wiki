## 基本的な進行メカニクスとアップグレードツリーの概要

*Legion Breaker*におけるキャラクターの強化は、敵を倒して獲得したゴールドのみを消費して進める段階的なスキルツリー方式を採用しています。ラウンド間に自由にステータスをリセットできる一般的な防衛ゲームとは異なり、ツリー上での選択はそのセーブデータにおいて永続的な決定となります。1回のランは通常30〜60分程度続くため、ルート選びを最適化して「詰み（デッドエンド）」のビルドを回避することが極めて重要です。

アップグレードツリーは、主に「攻撃呪文」「軍勢の召喚」「肉体的な耐久力（生存能力）」という3つの系統に横方向へ分岐しています。攻撃ノードは主軸となる魔法弾の基礎ダメージ、爆発範囲、連射速度を強化し、軍勢ノードは前線を維持する自律ユニットを召喚します。生存ノードは最大HPの増加や敵撃破時のパッシブなライフ吸収効果をもたらします。

```
[基本魔術士 (Basic Spellcaster)] 
   ├── 呪文ダメージ＆範囲攻撃（Resounding Fragments）
   ├── 軍勢召喚（Oathsworn Guard ➔ Temple Huntsmen）
   └── 生命力（Fortitude ➔ Spirit Drain）
```

コミュニティ内で共有されているプレイヤーの検証結果からも、これら3系統のバランスを取ることが不可欠であると強調されています。手持ちのゴールドを軍勢や弾丸の威力だけに偏って注ぎ込むと、環境ギミックの持続ダメージで力尽きてしまいます。一方で防御に過剰投資すると、高耐久な敵指揮官に対する処理速度が落ちて押し切られてしまいます。

| 進行系統 | 主な役割 | ゴールドの優先度 | 戦略的価値 |
| :--- | :--- | :--- | :--- |
| **Active Spellcraft（主動魔術）** | 主力弾のダメージ、爆発規模、破片発生率の強化 | 高（序盤＆終盤） | 密集した敵の群れの殲滅やボスへの瞬間火力に不可欠。 |
| **Army Reinforcements（軍勢の増援）** | 自動で戦う槍兵や弓兵を召喚して戦線を維持 | 中（中盤） | パッシブな前線防衛を担い、プレイヤーがエリート敵への呪文照準に集中可能。 |
| **Vitality & Leech（生命力＆吸収）** | 最大HPの底上げと敵討伐時のライフ回復効果 | 最重要（常時） | 各アリーナで毎秒発生するブライトダメージに対抗する必須手段。 |
| **Resource Efficiency（資源効率）** | ノードの取得コスト低減とゴールドドロップ率の向上 | 状況次第 | 終盤のマイルストーンとなる高額強化を前倒しで獲得するのに有用。 |

**『Legion Breaker』のアンロック**を慎重に計画することで、基礎的な火力と生存能力が安定する前に、優先度の低いユーティリティパークへ貴重な資金を浪費してしまう事態を防げます。

## 必須の呪文アップグレードと攻撃系アンロック

メインとなる秘術の魔法弾は、ラン全体を通じて最も信頼できる武器です。キャンペーン開始直後は、標準的な弾丸では最弱のスケルトン兵1体を倒すのにすら直撃が2発必要となります。攻撃系統に早期投資してキルタイム（TTK）を大幅に短縮することで、頼りない単体射撃を壊滅的な範囲制圧攻撃へと進化させましょう。

攻撃ツリーにおける最も劇的な転換点となるノードが**Resounding Fragments**です。このノードをティアIIおよびIIIまで強化すると、呪文が命中した際に炸裂し、周囲のアンデッドへ二次破片をまき散らすようになります。跳弾する破片が追加のダメージ判定を次々と引き起こすため、手動でエイムせずとも群がる雑魚敵を一掃できるようになります。

```
[主力の魔法弾] ➔ [威力＆弾速強化] ➔ [Resounding Fragments I] ➔ [Fragments II＆IIIによる跳弾]
```

激しい乱戦では、カーソルの位置取りと発射タイミングの管理が極めて重要であるとプレイヤー間で指摘されています。現行のデモ版ではカーソル上に射撃クールダウンゲージが表示されないため、呪文強化による固有の発射テンポを身体で覚え、次の射撃間隔を的確に予測することが重要です。

| 呪文ノード名 | 解放ティア | ゲーム内効果 | 実戦での運用 |
| :--- | :--- | :--- | :--- |
| **Arcane Potency I–III** | ティア1 基本 | 着弾時の基礎弾丸ダメージが増加 | 基本スケルトンのTTKを2発から確殺1発へ短縮。 |
| **Rapid Invocation** | ティア1 中盤 | 弾丸発射時の詠唱ディレイを短縮 | 足の速いグールの群れに詰められた際の殲滅速度を向上。 |
| **Resounding Fragments I** | ティア2 分岐 | 着弾時に弾丸が飛び散り周囲に破片ダメージ | 密集した敵の防衛ラインを面で削り落とす。 |
| **Resounding Fragments II–III** | ティア3 発展 | 破片が隣接する標的間を連続して跳弾 | 大規模な連鎖爆発を発生させ、大群を一瞬で蒸発させる。 |
| **Calamity Blast** | ティア3 頂点 | 中心弾が爆発的な火球へと変化 | ボスの装甲ゲージを削り取るための必須単体バースト手段。 |

序盤の攻撃的な**『Legion Breaker』のアンロック**を進める際は、基本の敵を1撃で倒せるようになるまで基礎ダメージの向上を優先してください。その基準ダメージに達した後は、敵の密度に対処するため、破片の発生効果と攻撃速度の強化へシフトしましょう。

## 軍勢の増援：槍兵と狩人のアンロック

押し寄せるアンデッドの大群を、プレイヤー1人だけで食い止める必要はありません。スキルツリーの下半分は軍勢の雇用に充てられており、プレイヤーの照準とは独立して動く強固な兵士の前線を構築できます。軍勢を拡張することで、*Legion Breaker*は単なる手動エイムのシューターから、ハイブリッドなオートバトラーへとゲームプレイが変化します。

軍勢の育成ルートは**Oathsworn Guard**から始まります。これは戦場に直接配置され、前進してくる敵を近接攻撃で迎え撃つ規律ある槍兵です。Oathsworn Guardを強化すると、兵士の物理耐久力、槍の突き攻撃のリーチ、部隊の最大展開数が増加し、敵がプレイヤーの元へ到達する前に足止めする頑丈な防壁となってくれます。

軍事ツリーをさらに進めると**Temple Huntsmen**が解放されます。この遠距離弓兵をアンロックするには、前提条件として**Oathsworn Guard III**を完全に取得する必要があります。雇用されたHuntsmenは空中や遠方の敵へ矢の雨を降らせ、呪文が直撃する前に敵の体力を削ってくれます。

| 軍事ユニット / パーク | 前提ノード | ユニットの役割 | 戦術的な強みと限界 |
| :--- | :--- | :--- | :--- |
| **Oathsworn Guard I** | 基礎軍事基盤 | 前衛の近接槍兵 | 初期の突進を受け止める壁。単体への火力は控えめ。 |
| **Oathsworn Guard II** | Oathsworn Guard I | 強化型の方陣（ファランクス） | 防御力向上と広範囲の突き攻撃で複数の這い寄る敵を迎撃。 |
| **Oathsworn Guard III** | Oathsworn Guard II | 精鋭の槍壁（スピアウォール） | 部隊数が最大化。遠距離ユニット解放のための必須前提ノード。 |
| **Temple Huntsmen I** | Oathsworn Guard III | 定置型の後衛弓兵 | 高速な一斉射撃を展開。前衛が崩壊すると非常に脆い。 |
| **Temple Huntsmen II** | Temple Huntsmen I | ロングボウの狙撃手 | 射程が大幅に伸び、接近してくるボスを遠距離から削り始める。 |

弓兵を最大展開すると、ボスに対して大まかに照準を合わせるだけで敵が溶けていく半自動的なプレイスタイルが可能になります。しかし、近接ユニットの強化を怠ると、素早く接近する大群にHuntsmenがあっさり蹂躙されてしまうため注意が必要です。

## 生存パーク：ブライトダメージと進行不能の対策

*Legion Breaker*で最も見落とされがちな要素が**ブライトダメージ（Blight Damage）**です。各アリーナにおいて、プレイヤーキャラクターは毎秒自動的に一定の体力を失い続けます。この環境ダメージは実質的なタイムリミットとして機能し、素早いウェーブクリアを強制してきます。適切な生存系アップグレードを取得していなければ、敵が画面の半分まで到達する前にプレイヤーは倒れてしまいます。

この消耗に対抗するため、防御ツリーには相互に関係し合う2つのメカニクスが用意されています。それが**Fortitude**と**Spirit Drain**です。Fortitudeはプレイヤーの最大HPを底上げし、刻一刻と削られる環境ダメージに対する猶予時間を伸ばします。一方のSpirit Drainは、敵ユニットを倒すたびに体力を一定値即座に回復します。

```
[毎秒のブライトダメージ] <==== 対抗 ====> [Fortitudeによる最大HP増加] + [敵撃破時のSpirit Drain]
```

防御パークを無視して高難易度マップへ急行した場合、ゲームの進行が実質的に不可能（ソフトロック）になる危険性があることがコミュニティの検証で判明しています。現行ビルドでは、クリア済みの戦闘ステージを周回してゴールドを稼ぎ直すことができないため、Spirit DrainやFortitudeが不足した状態で終盤のボスステージに入ってしまうと、クリア不能に陥ることがあります。

| ボスステージ | 最低限必要なFortitude | 推奨されるSpirit Drain | 生存の目安 |
| :--- | :--- | :--- | :--- |
| **ボス1: Crypt Warden** | Fortitude I（基礎HP 3） | Spirit Drain I | 敵を倒さずに生存できる時間は約30秒。能動的な雑魚処理が必須。 |
| **ボス2: Bone Golem** | Fortitude II（HP 5〜6） | Spirit Drain I–II | 加速する中盤のスリップダメージを相殺するため、安定したミニオン討伐が必要。 |
| **ボス3: Evil Wizard** | Fortitude III（HP 8以上） | Spirit Drain III | 激しい持続スリップダメージ。ボスが召喚する使い魔を確実に刈り取る戦法が前提。 |

極限のプレイスキルがあれば「最小HP縛り」でのクリアも理論上は可能ですが、最初のボスに挑む前に**Spirit Drain I**を解放しておくことは、通常プレイにおいて実質的に必須です。パッチの更新状況や開発ロードマップに関する詳しい情報は、公式の[Legion Breaker itch.ioプロジェクトページ](https://baffledengineer.itch.io/legion-breaker)で最新のバランス調整を確認してください。

## 60分クリアのための最適進行ルート

1回の通しプレイで3体の主要ボスをすべて討伐するには、強化の行き止まりを避けつつ、徐々に硬くなる敵のHPに対応できるバランスの良い育成計画が必要です。手当たり次第にゴールドを配分すると攻撃力が分散し、敵の強化ペースについていけなくなります。

最も確実性の高い攻略法は、ランを明確な4つのフェーズに分割することです。序盤は固定ダメージの強化に専念し、次いで前衛の槍兵を配備、第2ボス突入前にSpirit Drainを確保することで、生存力と火力の上昇曲線を綺麗に一致させることができます。

| 攻略フェーズ | ゴールド配分の目安 | 必須のアンロック | 戦略目標 |
| :--- | :--- | :--- | :--- |
| **フェーズ1: 序盤の小競り合い** | 呪文70%、HP30% | Arcane Potency I–II, Fortitude I | 基本スケルトンを一撃で倒し、ステージ1のブライトダメージに耐える。 |
| **フェーズ2: 第1ボス準備** | 軍事50%、吸収50% | Oathsworn Guard I, Spirit Drain I | 前衛の防壁を構築し、ボス1戦でのHP低下を安定して回復する。 |
| **フェーズ3: 群れの掃討** | 呪文60%、軍事40% | Resounding Fragments I–II, Oathsworn III | 密集した群れを粉砕し、弓兵アンロックの前提条件をクリアする。 |
| **フェーズ4: 魔法使い決戦** | 呪文40%、防御60% | Temple Huntsmen I–II, Spirit Drain III | 自動攻撃による削りを維持しつつ、最終ボスの激しい呪文攻撃を耐え抜く。 |

このロードマップに沿って進めることで、手持ちの戦力が互いに補完し合います。槍兵が敵の足を止め、跳弾破片が密集地帯を焼き払い、高ランクのSpirit Drainが倒したミニオンを即時の体力回復へと変換してくれます。

## アップグレードの効果を最大化する上級戦闘のコツ

ツリー上のパークを解放するだけでは戦いの半分に過ぎません。アリーナ内でその投資効果を最大限に引き出すには、スマートな優先順位付けが求められます。特にSpirit Drainは「与えたダメージ」ではなく「敵を撃破した瞬間」にのみ発動するため、どの標的を狙うかが自身のHP残量に直結します。

- **ボス戦では取り巻きの雑魚を狙う:** 最終ボスであるEvil Wizardと戦う際、HPが減り始めているにもかかわらずボスだけに集中攻撃するのは危険です。周囲を這い回る小型のミニオンを撃ち抜き、Spirit Drainを発動させてHPゲージを満タンに保ちましょう。
- **弾丸の偏差撃ちを意識する:** 魔法弾には着弾までの弾速が存在します。突進してくる敵集団のわずかに前方（進行方向）を狙って撃つことで、初弾を着弾中心点へ正確に命中させ、Resounding Fragmentsの巻き込み範囲を最大化できます。
- **ボス戦直前にはある程度ゴールドを温存する:** ボスアリーナに入る直前にゴールドを使い切ってしまうのは避けましょう。予備のゴールドを手元に残しておけば、突入直後に想定以上のブライトダメージを受けたと感じた際、その場で状況に応じたFortitudeアップグレードを素早く購入してリカバリーできます。
- **敵を槍兵の陣形へ誘導する:** Oathsworn Guardの脇をすり抜けようとする敵を優先して狙いましょう。兵士たちに中央を抑えさせつつ、サイドを抜けてくる敵をプレイヤーが迎撃することで、強固な防衛ラインを崩されずに維持できます。

立ち回りの技術と、計画的な**『Legion Breaker』のアンロック**を連動させることで、アンデッドの軍勢を易々と退け、邪悪な魔法使いを最短時間で討伐できるはずです。

## よくある質問（FAQ）

### 『Legion Breaker』で最優先すべき序盤のアンロックは何ですか？
最も重要な序盤の**『Legion Breaker』のアンロック**は、「Arcane Potency I」と「Spirit Drain I」です。Arcane Potencyは初期スケルトンを倒すのに必要な攻撃回数を2発から1発に減らし、ウェーブの殲滅速度を大幅に向上させます。一方のSpirit Drainは、常に体力を削り続ける環境ブライトダメージを打ち消すために不可欠です。

### 弓兵ユニットのTemple Huntsmenはどうすればアンロックできますか？
Temple Huntsmenは最初から直接アンロックすることはできません。解放には明確な前提条件があり、**Oathsworn Guard**を全3ランクすべて購入する必要があります。槍兵をOathsworn Guard IIIまでアップグレードすることで、スキルツリー上でTemple Huntsmenの枝へと進むことが可能になります。

### 『Legion Breaker』でスキルツリーをリセット（振り直し）することはできますか？
現行のデモ版および初期開発ビルドには、スキルのリスペクト（振り直し）やゴールドの返還機能は実装されていません。ツリー上で行ったすべてのゴールド投資はそのセーブデータにおいて永続するため、進行不能（ソフトロック）を防ぐためにも、攻撃と防御のバランスを慎重に計画しながら強化を進める必要があります。

### Spirit Drainはボス敵に対してどのように機能しますか？
Spirit Drainは敵ユニットを「完全に撃破した時」にのみ体力を回復し、ダメージを与えただけでは発動しません。ボスは膨大なHPを持っているため、ボス本体を攻撃し続けても回復効果は得られません。体力を回復したい場合は、ボス戦中に定期的に召喚される小型の使い魔に照準を合わせ、連続して討伐することで回復を行いましょう。
