## コア戦闘システム：バトルメイジの仕組み

効率的な**Legion Breakerバトルメイジ**として立ち回るには、ダメージ出力がゲーム独自の消耗メカニクスとどのように相互作用するかを理解する必要があります。被弾するまでプレイヤーの体力が減少しない標準的な見下ろし型アーケードシューターとは異なり、『Legion Breaker』の戦闘は常に環境からの圧力（スリップダメージ）を受けながら展開します。

### ブライト（Blight）とスピリットドレイン（Spirit Drain）の力学

各ランにおける生存の最大の課題は、環境要因である「ブライト（Blight）」として受ける継続パッシブダメージです。各戦闘中、戦場に広がる浸食により、バトルメイジは毎秒体力を失い続けます。

この消耗に対抗するため、プレイヤーの呪文詠唱者は**スピリットドレイン（Spirit Drain）**に依存します。これは、自身の魔法や軍隊の攻撃によって敵を倒すたびに体力を回復する重要なパッシブメカニクスです。群れを素早く殲滅できない場合、敵が防衛線に物理的に到達したかどうかに関係なく、ブライトによって残りの体力が吸い取られ、敗北を喫することになります。

```
戦闘中の体力フロー：
[基礎HP + Fortitude] ---> 減少 [毎秒のブライトダメージ]
             ^
             | (回復)
             |
[Spirit Drain (敵撃破時のHP回復)] <--- トリガー [呪文の発動 & 軍勢による撃破]
```

### ターゲット指定の魔法弾 vs 範囲攻撃効果

基本攻撃は、カーソルに向かって放たれる魔法弾の連射です。タイミングと弾道が重要であり、孤立したはぐれ敵を狙うよりも、密集した群れに弾を放つ方がはるかに高いリターンを得られます。アップグレードにより、跳弾破片（Shard Bounces）や爆発バーストなどの追加効果（Proc）が解放され、1発の射撃が連鎖反応を引き起こし、アンデッドの小隊全体を一掃できるようになります。

| コア戦闘システム | 機能 | 戦略的優先度 |
| :--- | :--- | :--- |
| **アクティブスペルファイア** | カーソル位置を狙う高威力の魔法弾 | 前線を削り、ボスを叩くための主要なバーストツール |
| **ブライトダメージ** | 毎秒発生する継続的な体力減少 | 戦闘のペースを決定づけ、迅速かつ安定した撃破数を要求 |
| **スピリットドレイン** | 敵撃破時の固定値またはスケールするHP回復 | ブライトによる消耗を相殺する必須の維持メカニクス |
| **シャードバウンス** | 着弾時に分裂する副次的な投射物 | 密集した雑魚敵を一掃し、スピリットドレインを高速発動 |
| **不屈（Fortitude）** | 最大HPの上限を増加 | 長期戦における高ティアのブライトに対するバッファを提供 |

初期ビルドを試してみたいプレイヤーは、30〜60分の基礎的なキャンペーンループを体験できる[Legion Breaker on itch.io](https://baffledengineer.itch.io/legion-breaker)で直接タクティクスをテストできます。

## スキルツリーの進め方：バトルメイジ必須のアップグレード

**Legion Breakerのバトルメイジ**として成功するには、アップグレードグリッド上で最適なルートを描く必要があります。ウェーブをクリアして得られるゴールドで広大なスキルツリーを拡張し、純粋な攻撃魔法、ユニットの雇用、重要な防御パッシブの間で選択を行っていきます。

```
                  [基本呪文の習熟]
                           |
       +-------------------+-------------------+
       |                                       |
[火球 & シャードバウンス]             [不屈 & HP]
       |                                       |
[リザウンディング・フラグメント]        [スピリットドレイン I-III]
       |                                       |
       +-------------------+-------------------+
                           |
               [軍隊：オーススウォーン・ガード]
                           |
              [軍隊：テンプル・ハントマン]
```

### 攻撃呪文のスケーリング優先

基本呪文は、主要なゴールド稼ぎ手段であり、雑魚敵の一掃ツールでもあります。**シャードバウンス（Shard Bounces）**を解放すると、通常射撃が広範囲殲滅ツールへと進化します。**リザウンディング・フラグメント（Resounding Fragments）**などのアップグレードと組み合わせることで、1回の着弾から複数の副次的なヒットが発生し、ゴールドやスピリットドレインの機会を無駄にすることがなくなります。

*   **衝撃力 & 弾速（Impact Force & Velocity）:** 弾の到達速度を速め、足の速いスケルトンに対して必要な偏差撃ちの時間を短縮します。
*   **シャード発生（Shard Procs）:** 着弾時に分裂する破片弾を生成し、1射あたりのキル効率を大幅に向上させます。
*   **ファイアボール注入（Fireball Infusion）:** 爆発的なスプラッシュ範囲を追加し、装甲を持つアンデッドの塊を粉砕するために不可欠です。

### 防御の指標：不屈（Fortitude）vs スピリットドレイン（Spirit Drain）

よくある落とし穴は、基本的な生存能力を軽視して呪文の威力に過剰投資してしまうことです。最大HPが初期値のままだと、敵のウェーブ間のわずかな合間であっても、次の敵が現れる前にブライトによって体力が完全に枯渇してしまう恐れがあります。

| アップグレードノード | 前提条件 | ゲーム内効果 | ビルド重要度 |
| :--- | :--- | :--- | :--- |
| **スピリットドレイン I** | 初期呪文ブランチ | 敵を1体倒すごとに基礎HPを回復 | 自活のために最優先で取得すべき必須スキル |
| **不屈（Fortitude）I–III** | コア防御ライン | プレイヤーの最大HPを固定値で増加 | 高；ブライト急増による突然の敗北を防止 |
| **リザウンディング・フラグメント** | シャードバウンス I | 副次破片のダメージと跳弾範囲を強化 | 密集した軍勢に対する最高峰の攻撃スケーリング |
| **オーススウォーン・ガード I** | 中層ツリー | 進軍してくる歩兵を阻止する槍兵を召喚 | 欠かせない前線の肉壁役 |
| **テンプル・ハントマン I** | オーススウォーン・ガード III | 自動攻撃DPSを提供する支援弓兵をアンロック | 終盤の自動索敵サポート |

## 軍隊とのシナジー：槍兵と遠距離支援の統合

魔法による破壊はプレイヤーのカーソルから直接繰り出されますが、真の**Legion Breakerバトルメイジ**は地上部隊を指揮して戦場のスペースを制圧します。歩兵の支援がなければ、高HPのエリート敵が妨害されることなく前進し、密集した敵の群れではなく個々のタンク敵に強力な呪文を浪費させられることになります。

### 前線の要：オーススウォーン・ガード（Oathsworn Guard）

**オーススウォーン・ガード**は、レーン上に直接配置される頑強な槍兵です。彼らは単に削りダメージを与えるだけでなく、前進するアンデッド兵を物理的に食い止め、敵ユニットをぎゅっと密集させます。この密集状態により、プレイヤーのスプラッシュ呪文や跳弾破片の効率が最大化されます。

### 自動射撃：テンプル・ハントマン（Temple Huntsmen）

軍事ブランチをさらに進めると、規律ある弓兵である**テンプル・ハントマン**がアンロックされ、安定した遠距離支援を提供します。個々の矢のダメージはプレイヤーの主力魔法弾よりも低いものの、その自動索敵能力により、素早くHPの低い側面攻撃ユニットが前線をすり抜ける前に確実に排除されます。

| ユニットタイプ | 雇用ノード | 戦場での役割 | 相性の良い呪文 |
| :--- | :--- | :--- | :--- |
| **槍兵（オーススウォーン）** | オーススウォーン・ガード I–III | レーン封鎖、敵の誘導、エリートの足止め | ファイアボール / 範囲爆発ダメージ |
| **弓兵（ハントマン）** | テンプル・ハントマン I–II | 自動残敵掃討、飛行・高速ターゲットの迎撃 | シャードバウンスの追加効果 |
| **バトルメイジ（プレイヤー）** | プレイヤー固有ユニット | 高火力ピンポイント射撃、ボス撃破、戦術的指揮 | 精密なカーソルエイム |

## ボス攻略ステップバイステップ：3体のアンデッド軍指揮官を撃破する

キャンペーン構造では、アンデッドの復活を画策する邪悪な魔法使いとの最終決戦を含む、3つの異なるボス戦が**Legion Breakerバトルメイジ**に立ちはだかります。各ボス戦には厳格なDPSチェックと、より強力なブライト発生率が課されており、計画性のないビルドは容赦なく打ちのめされます。

### 戦闘1：クリプト・ウォーデン（The Crypt Warden）

最初の大きな関門であり、タフな単一ターゲットに継続ダメージを与えながら、雑魚敵のウェーブをさばく能力が試されます。基礎HPのみに頼っていると非常に危険です。プレイヤーの検証によると、**スピリットドレイン I**がない場合、初期のブライトの速度でも初期値の3HPは約30秒で枯渇します。

*   **攻略法:** カーソルをウォーデンの進行方向の少し前方に維持します。跳弾シャードで周囲のスケルトンを倒し、発生するスピリットドレインでHPバーを満たし続けながら、ボスを少しずつ削っていきます。

### 戦闘2：ボーン・コロッサス（The Bone Colossus）

2体目のボスは、重装甲の護衛を率いて戦場に現れます。ボーン・コロッサスは高い物理防御力を誇るため、槍兵が二次ウェーブを抑え込んでいる間に、持続的な直接ヒットを叩き込む必要があります。

*   **攻略法:** 交戦前に**オーススウォーン・ガード**のランクを最大化しておきます。槍兵にフィールド中央でコロッサスを釘付けにさせ、プレイヤーはその頭上に直接呪文を雨あられと降らせます。HPが50%を下回った場合は、1〜2回の斉射を雑魚敵の群れに向けて放ち、急速回復を発動させましょう。

### 戦闘3：エビル・ウィザード（The Evil Wizard）

最後の決闘は、敵対する魔法使いとのバトルメイジ対決です。エビル・ウィザードはレーンを闇の魔法で満たしながらステージ全体のブライトダメージを激化させるため、高い瞬間火力（バーストDPS）と引き上げられた最大HPが必須条件となります。

## 高難易度ランでの高度な戦術とソフトロックの回避

インクリメンタルゲームは試行錯誤が醍醐味ですが、リソース配分を誤ると進行が立ち往生（詰み・ソフトロック）してしまうことがあります。コミュニティの報告によると、最小HP縛りプレイを試みたプレイヤーは、最初の投射物が敵に命中する前に初期ブライトが回復を上回り、詰んでしまう状況に頻繁に遭遇しています。

### 体力エコノミーの管理

**Legion Breakerバトルメイジ**が決してクリア不能なステージに閉じ込められないようにするためには、常に攻撃スケーリングと純粋な生存能力の間で経済的なバランスを取る必要があります。プレイヤーフィードバックにより、安定した進行のための重要なしきい値が明らかになっています。

```
ラン生存しきい値：
ステージ 1: 最低 3 HP  + スピリットドレイン I
ステージ 2: 最低 3〜5 HP + スピリットドレイン II
ステージ 3: 最低 8 HP (不屈 III) + スピリットドレイン III
```

1.  **回復を敵撃破だけに頼りすぎない:** スピリットドレインは強力ですが、ボス戦では雑魚敵のスポーンが少なくなるタイミングが多々あります。「不屈」による十分な最大HPがないと、雑魚敵がいない空白時間中にブライトによって倒されてしまいます。
2.  **偏差撃ちを意識する:** 投射物には明確な弾速があります。移動する敵を直接狙うと弾が外れてしまいます。照準レティクルは、進軍する敵の隊列の2キャラ分ほど前方に置きましょう。
3.  **スキルツリー全体を把握する:** スキルツリーは横方向に広がっていくため、ゴールドを消費する前に利用可能なすべてのルートを確認してください。基本呪文のダメージを強化せずに補助部隊ばかりを急いで解放すると、全体の戦闘効率が低下する恐れがあります。

## Legion Breaker バトルメイジビルドに関するよくある質問

### Legion Breakerバトルメイジとして生存力を最大化するにはどうすればよいですか？
生存力を最大化するには、**不屈（Fortitude）**アップグレードと複数ランクの**スピリットドレイン（Spirit Drain）**を組み合わせるのが基本です。不屈が最大HPの上限を引き上げ、スピリットドレインが自身や軍隊が敵を倒すたびに失われた体力を回復します。これによりステージのブライトによる持続ダメージを直接相殺し、長期にわたるボス戦でも生き残りやすくなります。

### 槍兵や弓兵を雇わずにラスボスを倒すことはできますか？
コミュニティの縛りプレイ動画などでは単独スペルキャスタービルドでもクリア可能であることが実証されていますが、軍隊ユニットをスキップすると難易度は跳ね上がります。槍兵はエリート敵を物理的に足止めし、魔法破片が最大の密集効率を発揮できるようにしてくれます。彼らがいないと、ボスに呪文を集中させている間に素早いアンデッドに防衛線を突破されるリスクが高まります。

### 敵の攻撃を受けていないのに突然敗北してしまう原因は何ですか？
突然の敗北は、ほぼ確実に環境ギミックである**ブライトダメージ（Blight Damage）**が原因です。戦場では毎秒自然に体力が削られます。魔法弾を外したり、敵のスポーンペースが落ちたりすると、スピリットドレインによるHP補充が追いつかなくなり、バトルメイジが消耗死してしまいます。

### 序盤を効率よく進めるための最も効果的なアップグレードルートは何ですか？
まずは環境による体力減少に対処するために**スピリットドレイン I**を解放し、その直後に集団殲滅力を倍増させる**シャードバウンス（Shard Bounces）**を取得してください。基本的な群れ処理能力を確保したら、最初のチャプターボスに挑む前に**不屈 I**に投資し、**オーススウォーン・ガード**の最初のランクを雇用するのがベストです。
