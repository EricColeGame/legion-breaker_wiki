## インストール手順とトラブルシューティングガイド

**Legion Breakerのダウンロード**とセットアップは極めてシンプルですが、古いWindows環境ではドライバーの競合や予期せぬ不具合が稀に発生することがあります。

以下に、ゲームのインストールとファイル整合性の確認手順をまとめました。

1. デスクトップでSteamクライアントを起動し、自身のアカウントにログインします。
2. ライブラリから本作を検索するか、ストアページからアクセスします。
3. **「インストール」**を選択し、対象ドライブに500MB以上の空き容量があることを確認します。
4. インストール完了後、**「プレイ」**を押して初回起動時のDirectXランタイム自動チェックを実行します。
5. ゲーム内設定メニューで解像度を調整し、モニターのリフレッシュレートに合わせてフレームレート制限を設定します。

数百体のユニットが入り乱れる激しい戦闘でパフォーマンスの低下を感じた場合は、以下のトラブルシューティング表を参考にしてください。

| 発生する問題 | 考えられる原因 | 推奨される解決策 |
| :--- | :--- | :--- |
| **起動時のDirectX 11クラッシュ** | GPUドライバーの破損または旧バージョン | グラフィックドライバーを更新。Microsoft公式からDirectXエンドユーザーランタイムを再インストール |
| **大規模ウェーブ時の微小なカクつき** | バックグラウンドでのデータ読み込み負荷 | Steamのストレージ管理メニューからゲームファイルをSSDへ移動 |
| **セーブデータが反映されない** | Steamクラウドの同期エラー | ネット接続を確認。ライブラリでゲームを右クリック＞プロパティ＞インストール済みファイル＞「ゲームファイルの整合性を確認」を実行 |
| **ノートPCでの低フレームレート** | 内蔵グラフィックス（iGPU）での誤動作 | Windowsのグラフィック設定から、本ゲームの実行ファイルを専用GPU（Nvidia/AMD）で動かすよう指定 |

これらの対策を講じることで、画面全体がスペルやミニオン、パーティクルエフェクトで埋め尽くされる高難易度ボス戦でも、安定したフレームレートで**Legion Breaker**を楽しむことができます。

## ネクロマンサー・キングを討伐するための上級戦術ガイド

キャンペーンの最終関門である「ネクロマンサー・キング」を倒すには、正確な立ち回りと状況に応じた戦術判断が不可欠です。ステージが進むにつれて、ボス戦には無敵シールド、レーンを一掃する衝撃波、スケルトンの高速蘇生など、多彩なギミックが登場します。

キャンペーン中盤から終盤にかけては、以下の戦略を意識して立ち回りましょう。

* **兵士の召喚タイミングを分散させる:** ボスのフェーズ移行前に資金を一気に投入して兵士を呼び出すのは避けてください。召喚のタイミングをずらすことで、ボスが広範囲攻撃を放った直後にも新鮮な聖なる騎士部隊を前線へ補充できます。
* **ノックバックと移動速度低下（スロウ）を優先する:** 強力な大型モンスターが防衛ラインに到達してしまっては、どれほど攻撃力が高くても意味がありません。氷結やスタン効果にスキルポイントを振り、危険な敵を主力スキルの射程内に留め続けましょう。
* **属性耐性に応じて魔法を切り替える:** 一部の戦場には、炎属性に高い耐性を持つ重装アンデッドが登場します。攻略に行き詰まった場合は、スキルをリスペックして純粋な秘術ダメージや味方部隊の物理ダメージに特化させましょう。
* **ゴールド稼ぎの周回を惜しまない:** インクリメンタルゲームにおいて、時間効率は非常に重要です。特定のボス戦で苦戦する場合は、1つ前のステージに戻って高速周回を2〜3回行い、ステータスを十分に底上げしてから再挑戦しましょう。

スキルツリーの継続的な強化と的確な部隊配置を極めれば、新米魔法使いから偉大なる大魔道士への旅路は、最初の一歩から最終決戦まで満足感に満ちたものになるはずです。

### 『Legion Breaker』はポータブルゲーミングPCやゲームパッドに対応していますか？
基本的にはキーボード＆マウスによる直感的なターゲティングを想定して設計されていますが、Steam Deckなどの携帯型ゲーミングPCでもマウスエミュレーション設定を使用することで快適にプレイ可能です。バッテリー消費を抑えて長時間のプレイを楽しむには、ゲーム内設定でフレームレートを60FPSに固定することをおすすめします。

### プレイ中に常時インターネット接続は必要ですか？
インターネット接続が必要なのは、最初の**Legion Breakerダウンロード**時、クラウドセーブ同期時、およびアップデートファイルの受信時のみです。インストールが完了すれば、シングルプレイヤーのインクリメンタルキャンペーンは完全オフライン環境でプレイできます。

### メインキャンペーンのクリア時間の目安はどのくらいですか？
ビルドの最適化度合いやプレイスタイルにもよりますが、メインキャンペーンを進行してネクロマンサー・キングを撃破するまでのプレイ時間は通常8〜15時間程度です。タレントツリーの完全制覇や別属性ビルドの開拓、クリア後のサバイバルチャレンジまでやり込む場合、さらに数十時間以上じっくりと遊ぶことができます。
